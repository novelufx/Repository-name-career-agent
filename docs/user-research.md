## 一、用户画像

目标用户是准备找实习的大学生，尤其是投递产品、运营、软件开发、AI 产品实习岗位的学生。

年龄 20-23 岁，大三或研一，有 1-2 段项目经历，但不确定怎么写进简历。技术背景或产品背景，熟悉互联网工具，但缺乏求职经验。

### 典型用户画像

小张，大三，计算机专业，目标是大厂前端实习。技术能力还行，跟着教程做了几个项目，但写简历的时候不知道怎么描述。他想投字节、腾讯这些大厂，但看别人的简历都写得很专业，自己的像流水账。他的痛点是不知道怎么把"用 React 做了个 xx 系统"写得更有说服力，不知道 JD 里要求的"熟悉 React 原理"到底要理解到什么程度。

小李，大三，信管专业，目标是 AI 产品实习。她的经历比较杂，做过社团运营、写过公众号、参与过一个小程序项目，但不知道怎么串成一条线。她想投 AI 产品岗，但不知道 JD 里说的"了解 AI 技术原理"要了解到什么程度。她的痛点是经历太散，不知道怎么包装成"产品思维"，不知道怎么在简历里体现自己对 AI 的理解。

小王，大四，非计算机专业，自学转码，目标是开发实习。他学了半年前端，做了两个练手项目，但简历上项目经历很少。他想投中厂，但不知道自己够不够格，不知道简历和 JD 的差距在哪。他的痛点是项目经历少，不知道怎么把手头的项目写好，不知道怎么弥补"非科班"的劣势。

## 二、用户典型场景

### 场景一：看到一个岗位，想投但不确定简历够不够格

小张在 Boss 直聘上看到字节的前端实习岗，JD 写了一堆要求，他不确定自己的简历是否匹配。

他的做法是把 JD 复制到 ChatGPT，问"我的简历和这个岗位匹配吗"，然后把自己的简历也贴进去。问题是 ChatGPT 的回答每次都不一样，有时候说匹配，有时候说不匹配，他不知道该信哪个。而且每次都要重新贴简历，很麻烦。

他需要的是一个工具能快速告诉他简历和 JD 的匹配度，指出具体哪里不匹配，给出可执行的建议。

### 场景二：项目经历写得不好，想优化但不知道怎么改

小李的简历上写了一段小程序项目经历："负责 xx 小程序的用户增长，通过 xx 活动实现用户从 100 到 1000"。

她觉得这段经历写得太简单了，但不知道怎么改。她去牛客网看别人的简历，发现别人都写得很详细，有数据、有方法论、有复盘。

她的做法是把这段经历发给 ChatGPT，问"帮我优化这段项目经历"，然后把 ChatGPT 的回答复制到简历上。问题是 ChatGPT 优化后的文字看起来很专业，但有些地方夸大了，她不确定面试的时候能不能圆回来。而且她不知道为什么这样改，下次遇到别的经历还是不会写。

她需要的是一个工具能告诉她这段经历哪里写得不好，为什么这样改更好，让她学会怎么写，而不只是帮她写。

### 场景三：面试前想练习，但找不到人陪练

小王投了几家公司，收到了面试邀请，想在面试前练习一下。

他的做法是去牛客网搜这家公司的面经，看看别人都被问了什么问题，然后自己在心里默默想答案。问题是看面经和自己想答案是两回事，真正面试的时候还是会紧张、会卡壳。而且他不知道自己的回答怎么样，有没有踩到面试官的雷点。

他需要的是一个工具能模拟面试场景，根据他的简历和 JD 提问，对他的回答给出即时反馈，告诉他哪里答得好、哪里需要改进。

## 三、用户核心痛点

| 痛点 | 严重程度 | 现有解决方案 | 不足 |
|------|----------|--------------|------|
| 不知道简历和 JD 的匹配度 | 高 | ChatGPT 分析 | 结果不稳定，每次不一样 |
| 项目经历写得像流水账 | 高 | 参考别人的简历 | 不知道怎么改，为什么这样改 |
| 面试准备没方向 | 中 | 牛客网刷面经 | 信息太散，没有针对性练习 |
| 找不到人帮忙改简历 | 中 | 找学长/付费咨询 | 学长忙，付费贵 |
| 不知道 JD 里某些要求到底什么意思 | 中 | 百度/问 ChatGPT | 信息碎片化，不知道该信谁 |

这些问题的根源是信息不对称和资源不均衡。

信息不对称是指：学生不知道 HR 和面试官在看什么，不知道 JD 里的要求到底要理解到什么程度，不知道自己的简历在 HR 眼里是什么样子。

资源不均衡是指：不是每个人都有学长帮忙改简历，不是每个人都能找到人陪练面试，付费咨询对学生来说太贵。

AI 可以解决这两个问题。AI 可以 24 小时在线，可以提供个性化分析，可以模拟面试场景，而且免费。

## 四、用户需求优先级

| 需求 | 优先级 | 原因 |
|------|--------|------|
| JD 和简历匹配度分析 | P0 | 最高频的痛点，直接影响投递决策 |
| 项目经历优化建议 | P0 | 用户最想提升的能力，也是最容易体现 AI 价值的地方 |
| 模拟面试练习 | P1 | 需求明确，但实现复杂 |
| JD 关键词解读 | P1 | 帮用户理解 JD 里某些要求的含义 |
| 面试反馈报告 | P1 | 面试练习后的复盘，提升学习效果 |
| 简历模板参考 | P2 | 不是核心需求，超级简历已经做得很好 |
| 面经整理 | P2 | 牛客已经有大量面经，不需要重复 |

MVP 阶段重点做 JD 和简历匹配度分析、项目经历优化建议、模拟面试练习这三个功能。这三个功能覆盖了用户从"看到 JD"到"准备好面试"的核心链路，也是最容易体现 AI 价值的地方。

## 五、用户旅程地图

用户带着"我想投这个岗位"的目标进入，经过 JD 分析、简历诊断、项目优化、模拟面试、反馈报告五个步骤，最后带着"我知道怎么改进"的收获离开。

**第一步：看到岗位，想投**

用户在 Boss 直聘、牛客网等平台看到一个岗位，觉得感兴趣，想投。他的情绪是期待，但有点不确定自己够不够格。他的行为是复制 JD，打开 CareerAgent。

**第二步：分析 JD，了解岗位要求**

用户粘贴 JD，系统分析出岗位的核心职责、必备技能、加分技能。他的情绪是"原来这个岗位要这些，我之前理解得不太对"。他的行为是看看分析结果，对照自己的情况，决定要不要继续投。

**第三步：诊断简历，看匹配度**

用户输入简历内容，系统给出匹配度评分和具体建议。他的情绪是"原来这里不匹配，那里可以优化"。他的行为是看看哪些地方需要改，决定先优化哪个。

**第四步：优化项目经历**

用户输入项目经历描述，系统给出优化后的版本和改进理由。他的情绪是"原来这样写更好，我学到了"。他的行为是把优化后的描述复制到简历上，或者学习优化思路自己改。

**第五步：模拟面试练习**

用户进入模拟面试，AI 面试官根据简历和 JD 提问，用户回答后获得即时反馈。他的情绪是"原来这个问题应该这样回答，我之前没想到"。他的行为是练习几轮，看看反馈，改进自己的回答。

**第六步：查看反馈报告**

用户查看综合评估报告，了解整体准备情况和下一步行动计划。他的情绪是"我知道自己哪里强、哪里弱，知道下一步该做什么了"。他的行为是根据报告的建议，继续优化简历或准备面试。

## 六、用户故事

### 快速判断要不要投这个岗位

小张在 Boss 直聘上看到一个前端实习岗，JD 写了七八条要求，他不确定自己够不够格。他把 JD 粘贴到 CareerAgent，系统分析出这个岗位主要要求 React、TypeScript、性能优化，其中 React 是必备，TypeScript 是加分，性能优化是加分。

他看了看自己的简历，React 用过，TypeScript 学过但没项目经验，性能优化只了解一点。他决定先投，同时补一下 TypeScript 的项目经验。

这个功能帮他快速做了投递决策，不用每次都去问 ChatGPT 还不确定答案对不对。

### 学会怎么写项目经历

小李的简历上写了一段小程序项目经历："负责 xx 小程序的用户增长，通过 xx 活动实现用户从 100 到 1000"。

她把这段经历输入 CareerAgent，系统给出优化后的版本："主导 xx 小程序用户增长策略，通过裂变活动和社群运营，3 个月内实现用户从 100 到 1000 的增长，日活提升 300%"。

系统还告诉她为什么这样改更好：加了"主导"体现 ownership，加了"裂变活动和社群运营"体现方法论，加了"3 个月内"体现时间维度，加了"日活提升 300%"体现量化成果。

她学到了优化思路，下次遇到别的经历也知道怎么写了。

### 面试前有地方练习

小王投了几家公司，收到了面试邀请，想在面试前练习一下。

他进入 CareerAgent 的模拟面试，系统根据他的简历和 JD 生成了问题："请介绍一下你做的 xx 项目，遇到了什么技术挑战，怎么解决的？"

他回答后，系统给出反馈：优点是回答有条理，提到了具体的技术方案；改进点是没有说清楚遇到了什么挑战，可以补充一下遇到的问题和解决过程。

他练习了几轮，改进了自己的回答，面试的时候更有底气了。

## 七、产品机会点

### 现有方案的不足

ChatGPT 门槛高，需要用户自己设计 prompt，结果不稳定，每次回答不一样，没有工作流，每次都要重新描述背景。

牛客网信息太散，面经质量参差不齐，没有个性化指导，看完了面经还是不知道怎么准备。

超级简历只管排版，不管内容，没有 JD 匹配功能，项目经历优化能力很弱。

### CareerAgent 的机会

把 JD 分析、简历诊断、项目优化、模拟面试、反馈报告这些割裂的需求，用 AI 串联成一个完整的流程。

降低使用门槛，不需要设计 prompt，不需要注册登录，打开就能用。

提升结果稳定性，通过专业的 prompt 设计和结构化输出，让分析结果更可靠。

### 差异化优势

相比 ChatGPT：更低的使用门槛，更稳定的结果，更完整的工作流。

相比牛客网：更结构化的分析，更个性化的指导，更针对性的面试练习。

相比超级简历：更深入的内容优化，不只是模板，而是帮用户理解怎么写更好。

## 八、为什么选择这个方向

我自己也在准备投 AI 产品实习，所以这个项目来自真实需求。

我在准备简历的时候发现，用 ChatGPT 改简历确实有用，但每次都要重新描述背景，结果也不稳定。我去牛客网看面经，信息太散，不知道怎么系统准备。我找学长帮忙改简历，学长很忙，反馈很慢。

所以我想要一个工具，能把这些需求串起来，让我像流水线一样完成求职准备。

技术上，这个项目用 React + TypeScript + Vite + Tailwind CSS，前端技术我比较熟悉。AI 部分用小米 MiMo 大模型 API，兼容 OpenAI 格式，接入简单。MVP 阶段可以先用 mock 数据演示，不需要真实的 API Key，降低展示门槛。

这个项目能体现产品能力：需求分析、竞品分析、PRD、Prompt 设计、效果评估。能体现技术能力：React 组件开发、状态管理、API 集成、Tailwind CSS 样式。能体现 AI 产品思维：不只是调用 API，而是设计完整的 AI Agent 工作流。

对于投 AI 产品实习的岗位，这个项目能展示我对 AI 产品的理解和实践能力。

## 附录

### 调研方法

用户访谈：5 个正在找实习的同学，包括产品岗、技术岗、转码岗。

问卷调查：收集了 20 份问卷，了解大学生求职时的主要痛点。

竞品体验：亲自体验了超级简历、牛客网、ChatGPT、AI 面试工具等产品。

### 调研发现

大学生求职时最大的痛点是不知道怎么写简历和怎么准备面试。

大多数人已经在用 ChatGPT 改简历，但对结果不太满意，主要是不稳定和没流程。

牛客网的面经很值钱，但信息密度低，需要自己整理。

AI 面试工具的需求是真实的，但大多数产品只做面试不做简历。
